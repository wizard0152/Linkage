# Linkage

Головоломка от первого лица о тросах, натяжении, массе и инерции.

## Среда разработки

- Unreal Engine **5.7.4**, Windows x64.
- Visual Studio 2022: Desktop development with C++, Game development with C++, Windows SDK.
- Git и Git LFS (`git lfs install` перед получением бинарных ассетов).
- По умолчанию движок: `D:/UE_5.7`. Для другой установки задайте `LINKAGE_UE_ROOT`.

## Запуск

1. `Build.cmd` — собрать редактор.
2. `OpenEditor.cmd` — открыть проект. Play в редакторе запускает тестовую комнату.
3. `Play.cmd` — открыть комнату отдельным игровым окном.

Управление: **WASD**, мышь, **Space** — прыжок, **R** — перезапуск комнаты.
ЛКМ/ПКМ зарезервированы для будущих тросов, пока не выполняют действий.

Дополнительные команды из корня проекта:

```powershell
./Scripts/dev.ps1 -Action ProjectFiles
./Scripts/dev.ps1 -Action BuildGame
./Scripts/dev.ps1 -Action Smoke
```

Карта `/Game/Maps/L_Development`: пол, стены, ступень, платформа, верхние опоры и физические кубы 20/100 кг.
`CreateMap` создаёт её только при отсутствии и отказывается перезаписывать существующий уровень.
DX11 и простое динамическое освещение выбраны как лёгкая база прототипа; это не окончательные графические настройки.

## Статус

Это первоначальная среда. Хук из Velocity, управление натяжением, связывание объектов, ограничения поверхностей и перемотка ещё не перенесены.
Физические кубы пока обычные физические тела, специального взаимодействия тросом нет.

## Структура

- `Source/Linkage/Player` — персонаж и Enhanced Input.
- `Source/Linkage/Framework` — режим игры и проверка запуска.
- `Content/Maps` — редактируемые уровни.
- `Scripts` — сборка, запуск и создание первоначальной карты.
- `docs` — концепция, план и результаты проверки.

## Публикация

В проект не копируются город и сторонние материалы Velocity. Карта ссылается на базовые ресурсы установленного UE.
Лицензия на самостоятельное распространение исходников пока не выбрана; публичность репозитория сама по себе её не предоставляет.
